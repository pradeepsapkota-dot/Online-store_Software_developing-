# Online Store Management System

## Project Overview
The Online Store Management System is a Python application for managing products in an online store. It will use Streamlit to provide a simple graphical user interface and MySQL to store product information.

## Project Objectives
- Develop a working Python application.
- Connect the application to a MySQL database.
- Implement Create, Read, Update, and Delete (CRUD) operations.
- Provide a simple and user-friendly interface using Streamlit.
- Test the application and handle invalid input and errors.

## Intended Users
Store administrators who need to manage product information.

## Main Features
1. Add new products.
2. View all products.
3. Update product information.
4. Delete products.
5. Validate product data before saving it.

## Database
The application will initially use the `Product` table with these fields:
- `ProductID`
- `Name`
- `Category`
- `Price`
- `StockQuantity`

## Technologies
- Python
- Streamlit
- MySQL
- Git and GitHub
- pytest or unittest for automated testing

## Development Plan
1. Finalize requirements and project structure.
2. Connect Python to MySQL.
3. Implement product CRUD operations.
4. Build the Streamlit interface.
5. Add input validation and exception handling.
6. Write and run automated tests.
7. Complete documentation and prepare the final demonstration.
